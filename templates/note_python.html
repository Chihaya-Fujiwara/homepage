1. Python のインストール

任意のバージョンの Python を公式サイト（{{ 'https://www.python.org/' | rich }}）からダウンロードしてインストールします。Anaconda を使う場合は {{ 'https://www.anaconda.com/download' | rich }} からダウンロードします。

2. Visual Studio Code のインストール

VS Code を公式サイト（{{ 'https://code.visualstudio.com/' | rich }}）からダウンロードしてインストールします。

3. 仮想環境の作成と Jupyter のインストール

Anaconda ではあらかじめ Jupyter 環境が用意されているため、インストールするだけで Jupyter Notebook を使用できます。一方、Python 単体をインストールした場合は、Jupyter に必要なパッケージを別途インストールする必要があります。

まず仮想環境を用意します。検索バーに cmd と入力してコマンドプロンプトを起動し、仮想環境を置くディレクトリを作成します。ここでは C:\venv に jupyter という名前の仮想環境を作成します。

> cd C:\
> mkdir venv
> cd venv
> python -m venv jupyter

作成した仮想環境を有効化し、Jupyter 関連のパッケージをインストールします。

> C:\venv\jupyter\Scripts\activate
(jupyter) > pip install jupyter ipykernel

VS Code で .ipynb ファイルを開き、右上の「カーネルの選択」から上記の仮想環境の Python を選ぶと、ノートブックを実行できます。

1. Install Python

Download and install the desired version of Python from the official website ({{ 'https://www.python.org/' | rich }}). If you prefer Anaconda, download it from {{ 'https://www.anaconda.com/download' | rich }}.

2. Install Visual Studio Code

Download and install VS Code from the official website ({{ 'https://code.visualstudio.com/' | rich }}).

3. Create a Virtual Environment and Install Jupyter

Anaconda ships with a ready-to-use Jupyter environment, whereas a standalone Python installation requires the Jupyter packages to be installed separately.

First, prepare a virtual environment. Type cmd in the Windows search bar to open the Command Prompt, and create a directory for virtual environments. In this example, a virtual environment named jupyter is created in C:\venv.

> cd C:\
> mkdir venv
> cd venv
> python -m venv jupyter

Activate the environment and install the Jupyter packages.

> C:\venv\jupyter\Scripts\activate
(jupyter) > pip install jupyter ipykernel

Open an .ipynb file in VS Code and choose the Python interpreter of this environment via “Select Kernel” in the upper-right corner to run the notebook.

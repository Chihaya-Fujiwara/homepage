{{ '研究テーマ' if ja else 'Research Topics' }}

01

{{ 'ハロゲン化物単結晶の育成' if ja else 'Growth of Halide Single Crystals' }}

{% if ja %} 主にハライドペロブスカイト単結晶を、ブリッジマン–ストックバーガー法および気相輸送法により育成しています。 {% else %} Halide perovskite single crystals are grown mainly by the Bridgman–Stockbarger method and by vapor-phase transport. {% endif %}

02

{{ '光学特性の評価' if ja else 'Optical Characterization' }}

{% if ja %}フォトルミネッセンス、透過率、赤外吸収などの測定により、発光特性と光学吸収を評価しています。{% else %}Luminescence and optical absorption are evaluated by photoluminescence, transmittance, and infrared absorption measurements.{% endif %}

03

{{ '放射線検出特性の評価' if ja else 'Radiation-Detection Properties' }}

{% if ja %}中性子およびガンマ線に対するシンチレーション特性を評価し、放射線検出器への応用を検討しています。{% else %}Scintillation responses to neutrons and gamma rays are characterized with a view to applications in radiation detectors.{% endif %}

04

{{ '第一原理計算による無機材料の解析' if ja else 'First-Principles Analysis of Inorganic Materials' }}

{% if ja %}Quantum ESPRESSO や VASP を用いた電子状態計算により、発光機構や物性の起源を解析しています。{% else %}Electronic-structure calculations using Quantum ESPRESSO and VASP are employed to clarify luminescence mechanisms and the origins of material properties.{% endif %}

05

{{ '電子状態データベースの構築' if ja else 'Electronic-Structure Database' }}

{% if ja %}第一原理計算に基づき、無機材料の電子状態データベースを作成しています。{% else %}An electronic-structure database of inorganic materials is being constructed on the basis of first-principles calculations.{% endif %}

06

{{ '解析ソフトウェアの開発' if ja else 'Analysis Software Development' }}

{% if ja %}光学特性評価のためのアプリケーションをはじめ、研究を支援するプログラムを Python で開発しています。{% else %}Software for optical characterization and other research-support tools are developed in Python.{% endif %}
